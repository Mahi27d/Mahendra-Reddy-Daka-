# Example: Start a Replica project in ChatGPT

Paste the master skill into the chat first, then send a message like this:

    /replica-recon

    Target app: https://example.com
    Platform: web
    MVP scope: account dashboard and its primary create/edit workflow
    Audience: small teams
    Constraints: beginner-friendly stack, low initial cost

    Use public docs/pages and screenshots I upload. Do not silently guess.
    Create replica/recon.md and replica/features.csv. Mark unverifiable
    features UNKNOWN. Cite sources and finish with the exact files I should
    save and the next mode to run.

Replace the example URL and workflow with the real target. Pick one concrete flow before asking for the full app.
