# replica-backend

> Wire the backend safely.

Use replica/architecture.md. Plan or implement database, migrations, authentication, authorization, files, email, jobs, payments and third-party integrations required by the selected MVP. Use official APIs and the user's own accounts. Start with sandbox/test mode. Provide .env.example with variable names only—never ask for real secret values—plus migrations, access controls, webhook idempotency and replica/backend.md. Never call the target app's private APIs or reuse its credentials. Distinguish generated code from code actually run. End with deliverables, unknowns, tests run/NOT RUN, and next mode.
