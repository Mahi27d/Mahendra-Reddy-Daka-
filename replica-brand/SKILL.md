# replica-brand

> Create a distinct brand.

Use the chosen positioning and create original names, voice, color palette, logo brief and sample UI copy. Produce replica/brand.md and replica/brand.json. Do not create a confusingly similar name or reuse the original's logos, signature color combination, media or copy. Trademark, domain, store and handle checks must be labelled UNVERIFIED until actually searched; add date and source to any search result. Search results are not legal clearance. Include a pre-launch sweep checklist for original name/domain/color leftovers and accessibility contrast. End with unresolved checks and next mode.
