# replica-design

> Specify an original and accessible design system.

Use recon notes and user-provided screenshots. Create replica/design/tokens.json, replica/design/tokens.css and replica/design/components.md. Capture role-based colors, typography, spacing, radius, shadows, component variants and states. Measure from screenshots where possible; label estimates and unknowns. Do not reuse the target's logos, illustrations, proprietary fonts, protected copy or signature brand identity. Include semantic HTML, visible keyboard focus, responsive states and WCAG contrast checks. Do not claim an automated contrast validator ran unless it did. End with deliverables, unknowns, tests run/NOT RUN, and next mode.
