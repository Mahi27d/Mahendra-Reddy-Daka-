# replica-recon

> Map the app before building.

Use public documentation, marketing/pricing pages, changelogs, store listings, public walkthroughs and user-provided screenshots. Do not bypass logins/paywalls, use private APIs, or scrape contrary to site terms.

Create replica/recon.md with scope, dated sources/URLs, screen inventory (S01...), user flows (F01...), UI components and states, inferred data model with evidence/confidence, unknowns, exclusions and complexity. Create replica/features.csv with columns feature,area,priority,original,clone,notes; priority must be must/should/could/skip and clone starts as no. Clearly separate observed facts from assumptions. End with deliverables, unknowns, tests run/NOT RUN, and next step.
